# Durrer, «The Cosmic Microwave Background»

**Ruth Durrer**, 2-е изд., Cambridge University Press, 2020.

Специализированный референс по физике реликтового излучения — строгий,
для тех, кто лезет в CMB всерьёз: спектр, поляризация, теория переноса
излучения, связь с космологическими параметрами.

**Регистр:** рабочая монография по узлу (CMB).
